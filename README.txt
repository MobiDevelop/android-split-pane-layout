ร้านชำ Suno prom (PWA)

ไฟล์ในแพ็ก: index.html, manifest.webmanifest, sw.js, โฟลเดอร์ icons
ต้องอัปโหลดทุกไฟล์ขึ้นโฮสต์ที่เป็น HTTPS (ใช้ผ่านไฟล์ในเครื่องแบบ file:// จะติดตั้งไม่ได้)

Netlify : ลากโฟลเดอร์นี้ไปวางที่ app.netlify.com/drop
GitHub Pages : อัปโหลดทุกไฟล์ขึ้น repo > Settings > Pages > Deploy from branch
Vercel : vercel deploy (ตอบ Other / ไม่มี build command)

ติดตั้ง: Android/Chrome/Edge กดปุ่ม "ติดตั้งแอป" ในหน้าเว็บ
         iPhone/iPad (Safari) แชร์ > เพิ่มไปยังหน้าจอโฮม
ครั้งแรกวาง Gemini API key ในช่อง "กุญแจร้าน" (เก็บในเครื่องผู้ใช้เท่านั้น)
